# BLACKBOX // Web Security Lab

ローカル/静的HTMLだけで遊べるCTF型のWebセキュリティ練習ゲームです。

## 遊び方
1. `index.html` をブラウザで開く
2. START LAB
3. ステージごとにHTMLソース、DevToolsのElements/Console/Application/Network、JavaScriptファイルなどを調査
4. 正しいコードを入力して進む

## 想定
- 全10ステージ
- 初見で約45〜75分
- スマホよりPC推奨
- 実在サイトへの攻撃は一切不要

## 難易度について
意図的に「ページ上には直接答えがない」問題を混ぜています。
ただし、答えは必ずこの配布物の中に存在します。
